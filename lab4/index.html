Лабораторна робота №4

Тема: Розробка бібліотек у JavaScript

Мета: створити JS-бібліотеку для сортування числових масивів різними методами та продемонструвати її роботу на звичайному й розрідженому масивах.

Бібліотека реалізована у вигляді псевдопростору імен SortLib.

1. Нерозріджений масив

Масив цілих чисел довжиною 120 без undefined-елементів.

2. Розріджений масив

Масив довжиною 120, у якому частина позицій є порожніми або undefined.

Пояснення реалізації

  • Усі методи працюють з одним і тим самим вхідним масивом, оскільки перед сортуванням створюється копія.
  • Параметр ascending визначає напрям сортування: true — за зростанням, false — за спаданням.
  • Якщо в масиві є undefined або «дірки» sparse-масиву, сортується лише числова частина, а невизначені елементи переносяться в кінець результату.
  • Для кожного методу виводиться кількість порівнянь та обмінів/переміщень.

Відкрий консоль браузера (F12), щоб побачити журнали роботи кожного алгоритму.
