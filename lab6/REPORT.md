# Лабораторна робота №6
## Робота із вводом користувача у JavaScript. Частина 2

### Мета роботи
Навчитись опрацьовувати ввід користувача у JavaScript, працювати з DOM, обробниками подій, таймером та завантаженням даних із сервера у форматі JSON.

---

## Короткі теоретичні відомості
DOM (Document Object Model) — це об’єктна модель HTML-документа. Вона дозволяє JavaScript отримувати доступ до елементів сторінки, змінювати їхній вміст, стилі та поведінку.

Основною точкою доступу до DOM є об’єкт `document`. Через нього можна знайти потрібні вузли сторінки, наприклад за допомогою методів `getElementById`, `querySelector`, `querySelectorAll` та інших.

Для реагування на дії користувача використовують обробники подій. Наприклад, при натисканні кнопки можна виконати функцію, яка змінює стан гри, перераховує кількість ходів або оновлює текст на сторінці.

Ajax-підхід дає можливість отримувати дані без повного перезавантаження сторінки. У цій лабораторній для такого завантаження використовується `fetch`, який читає JSON-файл з папки `data`, що імітує роботу сервера на GitHub Pages.

JSON (JavaScript Object Notation) — це текстовий формат збереження й обміну даними. Він зручний тим, що легко читається людиною і просто перетворюється на об’єкти JavaScript.

## Хід роботи
1. Було створено веб-застосунок гри **Lights Out** на чистих HTML, CSS і JavaScript.
2. Реалізовано ігрове поле розміром **5 × 5**.
3. Стан клітинок задається даними з JSON-файлу `data/puzzles.json`.
4. У JSON-файлі збережено **3 стартові конфігурації**, кожна з яких має власне значення **мінімальної кількості ходів для перемоги**.
5. При запуску гри випадково обирається один із трьох варіантів поля.
6. Реалізовано умову, за якої нове стартове поле **не повторює попереднє**.
7. Після натискання на клітинку змінюється стан самої клітинки та її сусідів зверху, знизу, зліва і справа.
8. Реалізовано лічильник **часу**, який показує, скільки минуло з початку поточної гри.
9. Реалізовано лічильник **ходів**.
10. Додано поле **цілі**, у якому показується мінімальна кількість ходів для поточної конфігурації.
11. Додано кнопку **New Game**, яка запускає нову гру **без перезавантаження сторінки**.
12. Після повного вимкнення всіх клітинок виводиться повідомлення про перемогу, витрачений час і кількість зроблених ходів.
13. Структуру проєкту організовано так, щоб її можна було легко розгорнути через **GitHub Pages**.

## Висновки
Під час виконання лабораторної роботи було створено інтерактивну браузерну гру із використанням JavaScript і DOM. У ході роботи було закріплено навички обробки дій користувача, динамічної зміни HTML-сторінки, застосування таймера та організації логіки гри без перезавантаження сторінки.

Також було відпрацьовано завантаження зовнішніх даних із JSON-файлу, що дозволяє імітувати роботу сервера в умовах GitHub Pages. Такий підхід робить застосунок більш гнучким, оскільки ігрові конфігурації можна змінювати окремо від основного коду програми.

У результаті лабораторна робота показала, як за допомогою JavaScript можна реалізувати повноцінну взаємодію з користувачем, обробку подій, оновлення інтерфейсу в реальному часі та отримання даних із зовнішнього джерела.

## Контрольні запитання

### 1. Що таке DOM?
DOM — це об’єктна модель документа, яка подає HTML-сторінку у вигляді дерева об’єктів і дозволяє JavaScript працювати з елементами сторінки.

### 2. Як називається глобальний об’єкт у DOM?
Основним глобальним об’єктом для роботи зі сторінкою є `document`.

### 3. Як за допомогою JavaScript отримати доступ до вузлів DOM?
Через методи `getElementById`, `getElementsByClassName`, `getElementsByTagName`, `querySelector`, `querySelectorAll`.

### 4. Що таке обробник події?
Обробник події — це функція, яка виконується у відповідь на певну дію користувача або браузера, наприклад клік миші, натискання клавіші чи завершення завантаження сторінки.

### 5. Які способи прив’язування обробників подій до вузлів DOM відомі? Які переваги і недоліки кожного з них?
1. **HTML-атрибут** (`onclick="..."`)  
   Перевага: просто.  
   Недолік: змішує HTML і JavaScript.

2. **Через властивість елемента** (`element.onclick = ...`)  
   Перевага: зрозуміло й просто.  
   Недолік: для однієї події можна призначити лише один обробник.

3. **Через `addEventListener`**  
   Перевага: сучасний і гнучкий спосіб, можна додавати кілька обробників для однієї події.  
   Недолік: трохи довший запис.

### 6. Коли спрацьовує подія DOMContentLoaded?
Подія `DOMContentLoaded` спрацьовує після того, як браузер повністю побудував DOM-структуру сторінки, але ще до повного завантаження всіх зображень та інших зовнішніх ресурсів.

### 7. Що таке Ajax?
Ajax — це підхід, який дозволяє JavaScript надсилати запити до сервера і отримувати дані без повного перезавантаження сторінки.

### 8. Що таке JSON?
JSON — це легкий текстовий формат обміну даними, який використовується для збереження і передачі структурованої інформації.
