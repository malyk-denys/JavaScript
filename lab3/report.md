# Лабораторна робота №3
## Тема
Застосування JavaScript для розв'язання прикладних задач обробки даних.

## Мета роботи
Навчитись застосовувати JavaScript для розв'язання прикладних задач обробки даних.

## Короткі теоретичні відомості
JavaScript - це мова програмування, яка використовується разом з HTML та CSS для створення динамічних вебсторінок. HTML відповідає за структуру сторінки, CSS - за зовнішній вигляд, а JavaScript - за логіку, обробку даних і взаємодію з користувачем. Код JavaScript виконується послідовно в браузері. Для виведення результатів під час налагодження часто використовується метод console.log().

JavaScript є мовою з динамічною типізацією, тобто тип змінної визначається під час виконання програми. Масиви в JavaScript можуть містити елементи різних типів. Для приховування змінних від глобальної області видимості зручно застосовувати IIFE - функцію, яка викликається одразу після оголошення. Такий підхід дозволяє ізолювати змінні та уникнути конфліктів імен.

## Хід роботи
1. Було отримано заготовки файлів SpeakHello.js, SpeakGoodBye.js, script.js та index.html.
2. У файлах бібліотек реалізовано шаблон IIFE, щоб змінні speakWord не потрапляли у глобальну область видимості.
3. У кожній бібліотеці створено окремий об'єкт:
   - helloSpeaker для виведення повідомлення Hello;
   - byeSpeaker для виведення повідомлення Good Bye.
4. У головному скрипті масив names також поміщено всередину IIFE, щоб він не був глобальним.
5. Реалізовано обхід масиву імен. Якщо перша літера імені - j або J, програма виводить Good Bye, інакше - Hello.
6. Для визначення першої літери використано методи charAt() і toLowerCase().
7. Додатково реалізовано власний спосіб селекції імен: якщо ім'я закінчується на голосну літеру (a, e, i, o, u, y), виводиться Hello, інакше - Good Bye.
8. Результати виводяться у консоль браузера.

## Контрольні запитання
1. **За що відповідає JavaScript у трійці HTML, CSS, JavaScript?**  
JavaScript відповідає за логіку, динаміку сторінки та взаємодію з користувачем.

2. **Що зумовлено тим, що JavaScript є мовою із динамічною типізацією?**  
Тип змінної визначається під час виконання програми, тому одна і та сама змінна може зберігати значення різних типів.

3. **На що вказує this всередині функції, яка не є конструктором?**  
У звичайній функції значення this залежить від способу виклику. У браузері без строгого режиму часто вказує на глобальний об'єкт window.

4. **Яка особливість створення конструкторів у JavaScript?**  
Конструктори зазвичай створюються як звичайні функції, які викликаються через new.

5. **На що вказує this всередині літерала об'єкта у JavaScript?**  
У методі об'єкта this вказує на сам об'єкт, через який було викликано метод.

6. **Чи можуть масиви у JavaScript містити різнотипні елементи? Чому?**  
Так, можуть, оскільки JavaScript має динамічну типізацію.

7. **Як дізнатись поточну довжину масиву у JavaScript?**  
За допомогою властивості length.

8. **Наведіть приклад розрідженого масиву та його утворення у JavaScript.**  
Наприклад: `let arr = []; arr[3] = "A";` У такому масиві елементи з індексами 0, 1, 2 будуть порожніми.

9. **Що таке замикання (closure) у JavaScript?**  
Це механізм, коли функція запам'ятовує змінні зі свого зовнішнього оточення навіть після завершення роботи зовнішньої функції.

10. **Чи визначені простори імен у JavaScript?**  
Окремих вбудованих просторів імен у класичному розумінні немає, тому для ізоляції часто використовують об'єкти, модулі або IIFE.

11. **Як визначається IIFE у JavaScript?**  
IIFE - це функція, яку оголошують у круглих дужках і одразу викликають, наприклад: `(function () { ... })();`
